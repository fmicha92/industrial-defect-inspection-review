# Scope and exclusions

## Included evidence layers

The repository is organized around public image datasets for visual defect inspection in identifiable industrial manufacturing contexts. It records domain, task, modality, annotation granularity, access, and suitability for synthesis-supported evaluation.

The research-paper layer is intended to include studies that use one or more overviewed public manufacturing datasets, apply an explicit data-synthesis component, and report a downstream machine-learning inspection outcome. Eligible synthesis components may be rule-based defect insertion, simulation, GAN-based generation, diffusion-based generation, generative augmentation, or a documented hybrid.

## Exclusions

- ordinary model-comparison papers with no explicit synthetic-data component;
- synthesis papers evaluated only by visual realism or distribution metrics without downstream inspection evidence;
- studies using only private datasets when no overviewed public dataset is evaluated;
- non-manufacturing image tasks unless they are retained as clearly labeled context rather than review evidence;
- claims that cannot be traced to the curated source state; and
- raw datasets, paper PDFs, and extracted copyrighted full text.

The graph may contain contextual or availability-unspecified records outside the final review scope. Inclusion in the graph is not the same as inclusion in the evidence synthesis.
