# Evidence and review resources

These resources accompany **Synthetic Data for Machine Learning in Industrial Visual Defect Inspection: A Review Centered on Public Datasets** by Michael Friedrich, Tobias Schlosser, and Danny Kowerko.

- [graph/](graph/README.md) contains the canonical linked Markdown notes, note schemas, and deterministic CSV/JSON exports.
- [review/](review/README.md) contains the review protocol, screening and extraction guidance, decision templates, and publication-material guidance.

The graph supports literature discovery and traceability. Its automated candidate lists are not the manuscript's retained evaluations. Human eligibility decisions and the conditions behind each reported result remain essential.

The [interactive website](../website/README.md) presents the manuscript-facing dataset registry and existing reported comparisons using its checked-in scientific assets. See the [main README](../README.md) for manuscript information and the [data dictionary](../docs/DATA_DICTIONARY.md) for graph-export fields.
