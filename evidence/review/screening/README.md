# Screening records

Store versioned, machine-readable screening ledgers here. Recommended columns are:

`record_id,title,year,doi,source,duplicate_of,title_abstract_decision,title_abstract_reason,full_text_status,full_text_decision,full_text_reason,reviewer,decision_date,source_note`

Use controlled decisions (`include`, `exclude`, `unclear`, `duplicate`) and retain the audit trail. Do not place PDFs or extracted full text in this directory.
