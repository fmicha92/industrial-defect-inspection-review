# Evidence extraction

Store manually confirmed evidence tables here. A synthesis-impact matrix should include at least:

`study_id,dataset,manufacturing_domain,task,annotation_level,synthesis_family,synthesis_method,downstream_model,real_only_baseline,comparison_condition,metric,baseline_value,synthesis_value,reported_change,split_or_protocol,source_note,verification_status,reviewer_notes`

Keep classification, detection, segmentation, and anomaly-detection results distinct. Record “not reported” rather than inferring missing values. Exhaustive table evidence should be the basis for broad manuscript comparisons.
