# Publication tables

This directory contains manuscript-facing publication tables:

- `dataset_registry.tex`: descriptions of the 61 public datasets.
- `synthesis_impact_longtable.tex`: detailed synthesis-impact evidence, methods, and supporting comparisons.

These publication sources are separate from the website. The website presents the checked-in JSON records and CSV reference tables in `website/public/`; its production build does not include LaTeX sources.
