# Publication material

This directory documents the organization of manuscript-facing material:

- [manuscript/](manuscript/) — LaTeX source and bibliography;
- [tables/](tables/) — publication tables tied to reviewed evidence;
- [figures/](figures/) — figures and their reproducible source files;
- [data/](data/) — versioned supplementary tables.

These directories contain guidance only. A compilable manuscript, `main.tex`, and `manuscript/library.bib` are not included, so LaTeX compilation is outside the supported repository checks.

The [website](../../../website/README.md) builds independently from its [scientific bundles](../../../website/public/data/) and [downloadable reference tables](../../../website/public/downloads/). It requires no publication-source processing for normal development or deployment.
