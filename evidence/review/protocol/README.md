# Review protocol

The protocol is dataset-centered: public manufacturing datasets define the reproducible evaluation substrate, and studies are then screened for explicit data-synthesis support and downstream ML inspection outcomes on those datasets.

Before a release, add or update:

- databases and platforms searched;
- complete search strings by platform;
- date ranges and final search dates;
- deduplication rules;
- title/abstract and full-text eligibility decisions;
- reviewer roles and conflict-resolution procedure; and
- fields in the final extraction form.

See `eligibility_criteria.md` and `search_strategy.md`.
