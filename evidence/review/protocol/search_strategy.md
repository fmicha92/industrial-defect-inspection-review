# Search strategy record

Record each search exactly as executed. At minimum capture:

| Field | Required content |
|---|---|
| Platform | Database, index, repository, or search engine |
| Search date | ISO date |
| Coverage | Years, document types, language, subject filters |
| Query | Exact platform-specific query string |
| Results | Number returned before deduplication |
| Export | Filename and format of the saved result set |
| Notes | API limits, unavailable fields, or deviations |

Search concepts should combine manufacturing/industrial inspection terms, defect/anomaly tasks, public dataset names, synthesis families, and downstream evaluation terms. Dataset-specific backward and forward citation searching should be documented separately from database searches.

This file is a protocol template; it must not be interpreted as evidence that a search has already been executed.
