# Review layer

The review layer connects the broad evidence graph to the manuscript's narrower synthesis-impact evidence base.

| Directory | Contents |
|---|---|
| [protocol/](protocol/) | Scope, eligibility, search strategy, and decision rules |
| [screening/](screening/) | Screening guidance and the location for decision ledgers |
| [extraction/](extraction/) | Guidance for manually confirmed evidence matrices and dataset registries |
| [templates/](templates/) | Header-only screening and extraction forms |
| [publication/](publication/) | Manuscript, table, figure, and supplementary-data guidance |

The generated [synthesis-impact candidates](../graph/exports/synthesis_impact_candidates.csv) are a pre-screen only. Record a human eligibility decision and reason before treating any study as included.

The [website](../../website/README.md) presents its checked-in manuscript-facing records and results. Its included-evidence collection and the graph's automated candidates have distinct scopes.
