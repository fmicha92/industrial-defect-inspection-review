# Emerging Concepts

Use this folder for new concepts that do not yet fit the stable vault taxonomy.

Promote a concept when it appears across multiple papers, anchors important links, or clearly belongs in a stable area such as `Concepts/`, `Tasks/`, `Datasets/`, `Benchmarks/`, or `Domains/`.

## Staging Rule

Every emerging concept note must link back to its source paper, at least one stable neighbor when available, and any related emerging notes from the same paper. If no stable neighbor is clear, set `candidate_parent: "not clear"` and explain the uncertainty in `## Related Concepts`.

Update this index with a wikilink whenever a new emerging concept note is created.
