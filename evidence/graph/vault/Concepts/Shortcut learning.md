# Shortcut Learning

## Definition

Shortcut learning occurs when a model relies on easy but non-causal cues, such as background texture, framing, lighting, or acquisition artifacts, instead of the intended defect evidence.

## Why It Matters

Shortcut learning can inflate validation accuracy while reducing robustness under new sites, viewpoints, cameras, or background conditions.
