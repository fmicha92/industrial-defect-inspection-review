# Solar Module Anomaly Classification

## Definition

Solar module anomaly classification assigns a thermal, infrared, or related inspection image of a photovoltaic module to nominal or anomaly categories.

## Why It Matters

Solar-farm infrared inspections produce imagery that often requires expert review. Automated anomaly classification can help prioritize maintenance and reduce manual inspection effort.

## Used In These Papers

- [[2020 - Infrared Solar Module Dataset for Anomaly Detection]] introduces [[InfraredSolarModules]] with 11 anomaly classes and one no-anomaly class for machine-learning research.
- [[2025 - Synthetic Dataset for AI-Driven Photovoltaic Fault and Damage Detection via UAV Thermal Imaging]] detects six synthetic PV fault categories in UAV thermal imagery.
