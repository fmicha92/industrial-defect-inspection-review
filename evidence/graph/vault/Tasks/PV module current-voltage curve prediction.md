# PV Module Current-Voltage Curve Prediction

## Definition

PV module current-voltage curve prediction estimates a photovoltaic module's I-V curve or electrical operating characteristics from non-contact measurements such as electroluminescence images.

## Why It Matters

Predicting I-V behavior from EL images can reduce dependence on direct flash-test measurements and supports module-level diagnostics, performance estimation, and long-term PV asset planning.

## Used In These Papers

- [[2025 - Advanced Photovoltaic Module Characterization Using Image Transformers for Current-Voltage Curve Prediction From Electroluminescence Images]] predicts 400-point normalized I-V curves from single EL images and evaluates derived electrical parameters.
