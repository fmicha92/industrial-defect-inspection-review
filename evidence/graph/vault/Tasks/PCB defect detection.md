# PCB Defect Detection

## Definition

PCB defect detection locates defects on printed circuit boards, often using template/test image pairs, bounding boxes, or reference comparison.

## Why It Matters

The processed PCB papers frame the task as automated optical inspection for electronics manufacturing, where both defect localization and defect type matter.

- [[2024 - A Dataset for Deep Learning Based Detection of Printed Circuit Board Surface Defect]] introduces [[DsPCBSD+]], a 10,259-image PCB surface-defect dataset with 20,276 bounding boxes across nine defect categories.
- [[2019 - Online PCB Defect Detector on a New PCB Defect Dataset]] evaluates online PCB defect detection on DeepPCB.
- [[2020 - HRIPCB a Challenging Dataset for PCB Defects Detection and Classification]] introduces HRIPCB for detection, classification, and registration.
