# Textile Defect Detection

## Definition

Textile defect detection identifies anomalies or defects in fabric and other textile materials using visual inspection, classical image processing, machine learning, or deep learning.

## Why It Matters

The textile review frames the task as quality control that can reduce human inspection fatigue, subjective judgments, and production costs.

## Used In These Papers


- [[2019 - A Public Fabric Database for Defect Detection Methods and Results]] supports fabric inspection, public benchmark.
- [[2021 - ZJU-Leaper A Benchmark Dataset for Fabric Defect Detection and a Comparative Study]] introduces [[ZJU-Leaper]] and five progressive benchmark settings for fabric defect detection.
- [[2022 - Defect Detection in the Textile Industry Using Image-Based Machine Learning Methods]] reviews image-based machine learning methods for textile defect detection.
- [[2024 - A Novel Dataset for Fabric Defect Detection Bridging Gaps in Anomaly Detection]] introduces [[Lusitano]] for one-class fabric anomaly detection.
- [[2025 - Dataset for Defect Detection in Textile Manufacturing]] introduces [[Batavia and Sarga woven fabric images]] for patch-level fabric defect case/control data.
- [[2024 - FabricSpotDefect An Annotated Dataset for Identifying Spot Defects in Different Fabric Types]] introduces [[FabricSpotDefect]] for spot-defect detection with COCO and YOLOv8 annotation exports.
- [[1996 - TILDA Reference Dataset Report]] documents [[TILDA]] as a textile surface-defect reference dataset with grayscale TIFF images and defect-description text files.
- [[2025 - AI-driven fabric classification]] documents the recording process for [[DME Fabric Defect Detection Dataset]]; use the Mendeley host record for the current defect-class dataset description.
- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] proposes [[STDAN]] for normal-only self-supervised fabric anomaly detection and evaluates it on [[FD_Dataset]], [[FabricSpotDefect]], and [[Lusitano]].
- [[2024 - Defect detection in textile manufacturing Improving findings using YOLOv5 versions]] evaluates YOLOv5s and YOLOv5x for AITEX-derived textile defect object detection with transfer learning and augmentation.
- [[2025 - Blind super-resolution network based on local fuzzy discriminative loss for fabric data augmentation]] improves downstream YOLOv5n fabric defect detection on [[DAGM2007]] using [[Super-resolution data augmentation]].
