# Question Answering

## Definition

Question answering predicts an answer from a question and context, often as a text span in a passage.

## Used In These Papers

- [[2019 - BERT Pre-training of Deep Bidirectional Transformers for Language Understanding]] fine-tunes BERT for SQuAD v1.1 and SQuAD v2.0 by predicting start and end answer positions.
