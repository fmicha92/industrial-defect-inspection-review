# Generative modeling

## Definition

Generative modeling learns a model of a data distribution so that new samples can be drawn from the learned distribution or its structure can be analyzed.

## Why It Matters

Generative modeling is the broader task behind learned synthetic data generation, including GANs, diffusion models, VAEs, and related model families.

## Used In These Papers

- [[2014 - Generative Adversarial Nets]] introduces [[GAN]] as an adversarial framework for generative modeling.
- [[2015 - Deep Unsupervised Learning using Nonequilibrium Thermodynamics]] introduces [[Diffusion models]] as a probabilistic generative modeling framework.
- [[2020 - Denoising Diffusion Probabilistic Models]] trains diffusion models for high-quality image generative modeling.
