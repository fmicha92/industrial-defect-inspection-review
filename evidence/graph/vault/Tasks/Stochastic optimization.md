# Stochastic Optimization

## Definition

Stochastic optimization minimizes or maximizes objectives where each update uses a noisy objective realization, such as a minibatch gradient.

## Used In These Papers

- [[2015 - Adam A Method for Stochastic Optimization]] proposes Adam for high-dimensional stochastic objectives.
