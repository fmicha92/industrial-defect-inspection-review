# Industrial Object Recognition

## Definition

Industrial object recognition classifies or recognizes industrial objects, tools, machine parts, or defected materials from images.

## Why It Matters

The processed Multipath VGG19 paper treats industrial object recognition and defect recognition as related classification tasks across multiple public industrial datasets.

## Used In These Papers

- [[2023 - Industrial Object and Defect Recognition Utilizing Multilevel Feature Extraction]] evaluates Multipath VGG19 on six public industrial-related image datasets.
