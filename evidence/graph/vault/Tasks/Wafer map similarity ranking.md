# Wafer Map Similarity Ranking

## Definition

Wafer map similarity ranking retrieves wafer maps with similar spatial failure patterns to a query wafer map.

## Why It Matters

Similarity ranking supports failure analysis by showing engineers prior wafers with related patterns rather than only assigning a class label.

## Used In These Papers

- [[2015 - Wafer Map Failure Pattern Recognition and Similarity Ranking for Large-Scale Data Sets]] defines the WMSR task and evaluates ranking with rotation- and scale-invariant wafer-map features.
