# Pre-post Diagnostic Assessment

## Definition

Pre-post diagnostic assessment measures how a population's scores change between an assessment administered before instruction and the same or comparable assessment administered after instruction.

## Used In These Papers

- [[1998 - Interactive-engagement versus Traditional Methods]] compares traditional and interactive-engagement introductory mechanics courses using pre/post conceptual diagnostic scores.
- [[2007 - Normalized Change]] studies how to summarize matched pre-test and post-test conceptual diagnostic scores using normalized change.
