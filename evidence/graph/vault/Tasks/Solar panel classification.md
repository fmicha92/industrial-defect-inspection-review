# Solar Panel Classification

## Definition

Solar panel classification predicts whether an image contains a solar photovoltaic system.

## Why It Matters

Image-level PV classification supports solar-adoption mapping when precise panel masks are unavailable or expensive to annotate.

## Used In These Papers

- [[2022 - SolarDK A high-resolution urban solar panel image classification and localization dataset]] benchmarks binary PV/no-PV classification from Danish aerial imagery.
- [[2025 - Comparative Deep Learning for RGB-Based PV Surface Fault Classification Using ResNet50 and EfficientNetB0]] performs six-class RGB PV panel surface fault classification on [[PV Panel Defect Dataset]].
- [[2024 - Deep Learning for Solar Panels Defect Classification Using Data Augmentation Strategies]] performs binary clean/defective solar panel image classification with ResNet50 and augmentation strategies.
