# Robotic Object Localization

## Definition

Robotic object localization estimates object positions from sensor observations so a robot can act on those objects.

## Used In These Papers

- [[2017 - Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World]] predicts tabletop object centers from single RGB images for robotic pickup.
