# Solar Cell Defect Detection

## Definition

Solar cell defect detection locates visual defects in solar-cell or photovoltaic-panel imagery.

## Why It Matters

The photovoltaic papers treat defect detection as a quality-control step for solar-cell and panel manufacturing.

## Used In These Papers




- [[2022 - Identifying Defective Solar Cells in Electroluminescence Images Using Deep Feature Representations]] supports electroluminescence images, deep feature representations.
- [[2023 - Deep-Learning-Based Automatic Detection of Photovoltaic Cell Defects in Electroluminescence Images]] supports photovoltaic cell defects, electroluminescence images.
- [[2021 - SIGAN A Novel Image Generation Method for Solar Cell Defect Segmentation and Augmentation]] supports solar cell defect segmentation, generative data augmentation.
- [[2024 - High-Precision Defect Detection in Solar Cells Using YOLOv10 Deep Learning Model]] applies YOLOv10x to [[EL Solar Cells Dataset]] and reports 98.5% mAP@0.5 for solar-cell EL defect detection.
- [[2024 - Enhanced Photovoltaic Panel Defect Detection via Adaptive Complementary Fusion in YOLO-ACF]] proposes YOLO-ACF for photovoltaic panel defect detection.
- [[2026 - IncepViTH-Net for Solar Panel Fault Detection and Classification]] uses brightness correction, [[U-Net]] segmentation, and [[IncepViTH-Net]] classification for solar panel faults.
- [[2025 - Lightweight Multiscale Feature Fusion Network for Solar Cell Defect Detection]] introduces [[LMFF]] and refined-label EL datasets for solar-cell defect segmentation.
- [[2026 - Diagnosing Shortcut Learning in CNN-Based Photovoltaic Fault Recognition from RGB Images]] audits whether CNN-based PV fault recognition uses panel evidence or shortcut context.
- [[2023 - PVEL-AD A Large-Scale Open-World Dataset for Photovoltaic Cell Anomaly Detection]] introduces [[PVEL-AD]] for photovoltaic-cell anomaly detection in EL images.
- [[Dataset of Solar Cells Defect Segmentation]] provides EL image segmentation datasets for solar-cell defect detection.
- [[ELPV Dataset]] provides labeled electroluminescence solar-cell images for visual identification of defective cells.
- [[EL-2019]] provides crack, finger-interruption, and defect-free EL image patches for SIGAN segmentation and augmentation experiments.
- [[BenchmarkELimages]] provides pixel-level electroluminescence masks for solar-cell feature and defect segmentation.
- [[2023 - A benchmark dataset for defect detection and classification in electroluminescence images of PV modules using semantic segmentation]] evaluates U-Net, PSPNet, and DeepLabv3+ baselines for solar-cell EL defect segmentation.
- [[2020 - Infrared Solar Module Dataset for Anomaly Detection]] introduces [[InfraredSolarModules]] for thermal module-level anomaly classes.
- [[2025 - Synthetic Dataset for AI-Driven Photovoltaic Fault and Damage Detection via UAV Thermal Imaging]] detects synthetic PV fault categories from UAV thermal images.
