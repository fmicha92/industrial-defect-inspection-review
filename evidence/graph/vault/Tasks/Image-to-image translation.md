# Image-to-image translation

## Definition

Image-to-image translation maps images from one visual domain into another, such as labels to photographs, photographs to semantic labels, or one appearance style to another.

## Why It Matters

It is a common task for learned generative synthesis because it can adapt visual appearance without requiring a new procedural scene specification.
