# Wafer Map Defect Classification

## Definition

Wafer map defect classification assigns wafer maps to spatial defect or failure-pattern classes so manufacturing engineers can connect yield patterns to likely process issues.

## Why It Matters

The processed wafer-map papers use this task to reduce manual inspection effort and support root-cause analysis in semiconductor fabrication.
