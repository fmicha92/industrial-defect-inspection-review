# Additive Manufacturing Defect Detection

## Definition

Additive manufacturing defect detection identifies defects or process anomalies in additively manufactured metal parts or in-process monitoring data.

## Why It Matters

The papers use machine learning for defect detection in laser-based additive manufacturing and wire-and-arc additive manufacturing settings.

## Used In These Papers

- [[2024 - Process Monitoring and Machine Learning for Defect Detection in Laser-Based Metal Additive Manufacturing]] reviews machine-learning process monitoring for laser-based metal additive manufacturing.
