# Document Recognition

## Definition

Document recognition extracts structured textual or numeric information from document images.

## Used In These Papers

- [[1998 - Gradient-Based Learning Applied to Document Recognition]] studies CNN and graph-transformer systems for handwritten digits, words, and check amounts.
- [[2003 - Best Practices for Convolutional Neural Networks Applied to Visual Document Analysis]] studies CNN training practices for visual document analysis.
