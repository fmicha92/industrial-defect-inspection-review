# Unsupervised Learning

## Definition

Unsupervised learning finds structure in data without explicit target labels.

## Typical Use

Useful for clustering, density modeling, representation learning, and anomaly detection when labels are missing or expensive.

## Vault Relevance

Central to [[Unsupervised anomaly detection]] and [[Unsupervised anomaly localization]], where normal samples are easier to collect than defect examples.
