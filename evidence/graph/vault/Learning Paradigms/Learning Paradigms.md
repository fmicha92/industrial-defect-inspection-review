# Learning Paradigms

Learning paradigms describe how a model learns from data. They are separate from model families such as [[Neural Networks]] or [[Classical ML]].

- [[Emerging Learning Paradigms]]

## Current Vault Emphasis

The processed industrial inspection papers currently emphasize supervised learning, unsupervised anomaly detection, synthetic-data pretraining, and [[Transfer learning]]. These paradigms matter because real defect labels are scarce, expensive, or unavailable.
