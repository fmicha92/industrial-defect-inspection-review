# Supervised Learning

## Definition

Supervised learning trains models from labeled examples, where each input has a target output such as a class label, mask, score, or numeric value.

## Typical Use

Useful for classification, regression, detection, and segmentation when reliable labels are available.

## Vault Relevance

Common in industrial inspection papers that evaluate [[Defect classification]] or [[Defect segmentation]] against labeled datasets.

- [[2021 - Mixed Supervision for Surface-Defect Detection From Weakly to Fully Supervised Learning]] supports mixed supervision, surface defect detection.
- [[2021 - Defect-GAN High-Fidelity Defect Synthesis for Automated Defect Inspection]] evaluates downstream supervised defect classification.
- [[2021 - Simulation-Based Data Augmentation for Quality Inspection of Structural Adhesive]] trains supervised object detectors with real and synthetic labels.
