# Reinforcement Learning

## Definition

Reinforcement learning trains an agent to choose actions through feedback from rewards, penalties, and state transitions.

## Typical Use

Useful for sequential decision-making, control, planning, robotics, simulation, and optimization.

## Vault Relevance

Not yet central in the processed inspection papers, but useful to keep separate from supervised and unsupervised model training.
