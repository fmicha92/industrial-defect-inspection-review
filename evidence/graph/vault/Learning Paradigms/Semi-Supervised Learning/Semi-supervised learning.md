# Semi-Supervised Learning

## Definition

Semi-supervised learning combines a small labeled set with a larger unlabeled set.

## Typical Use

Useful when labels are scarce but unlabeled data is plentiful, especially in image, text, and sensor-data settings.

## Vault Relevance

Relevant to industrial inspection when only a small number of labeled defects are available.
