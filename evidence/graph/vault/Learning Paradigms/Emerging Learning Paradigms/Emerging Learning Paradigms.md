# Emerging Learning Paradigms

Use this folder for learning setups, supervision regimes, or training paradigms that do not yet fit the stable `Learning Paradigms/` taxonomy.

Promote a learning paradigm when it appears across multiple papers, anchors important links, or clearly belongs in a stable learning paradigm folder.

## Staging Rule

Every emerging learning paradigm note must link back to its source paper, at least one stable learning paradigm or method neighbor when available, and any related emerging notes from the same paper. If no stable neighbor is clear, set `candidate_parent: "not clear"` and explain the uncertainty in `## Related Concepts`.

Update this index with a wikilink whenever a new emerging learning paradigm note is created.
