# Active Learning

## Definition

Active learning selects the most useful unlabeled examples for annotation so a model can improve with fewer labels.

## Typical Use

Useful when expert annotation is expensive and the model can identify uncertain, diverse, or high-value samples.

## Vault Relevance

Relevant to inspection settings where defect labeling requires domain expertise or costly manual review.
