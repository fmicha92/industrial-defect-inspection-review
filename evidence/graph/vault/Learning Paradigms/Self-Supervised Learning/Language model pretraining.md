# Language Model Pretraining

## Definition

Language model pretraining learns reusable language representations from unlabeled text before fine-tuning or adapting the model to downstream tasks.

## Why It Matters

BERT shows that pretraining deep bidirectional Transformer encoders can reduce the need for heavily engineered task-specific NLP architectures.

## Used In These Papers

- [[2019 - BERT Pre-training of Deep Bidirectional Transformers for Language Understanding]] uses masked language modeling and next sentence prediction for pretraining.
