# Self-Supervised Learning

## Definition

Self-supervised learning creates training signals from the data itself rather than from manually assigned labels.

## Typical Use

Useful for representation learning before downstream classification, detection, segmentation, or anomaly detection.

## Vault Relevance

Relevant when papers use pretraining, reconstruction, contrastive objectives, or synthetic pretext tasks before applying a model to inspection data.
