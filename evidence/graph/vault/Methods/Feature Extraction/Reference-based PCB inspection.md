# Reference-Based PCB Inspection

## Definition

Reference-based PCB inspection compares a tested PCB image against a template image to locate candidate defect regions before classification.

## Why It Matters

The processed HRIPCB paper uses reference comparison, registration, XOR, filtering, and mathematical morphology before CNN classification.

## Used In These Papers

- [[2020 - HRIPCB a Challenging Dataset for PCB Defects Detection and Classification]] uses reference-based localization as part of RBCNN.
