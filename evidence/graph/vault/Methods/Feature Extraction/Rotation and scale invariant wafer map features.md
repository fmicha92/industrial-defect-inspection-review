# Rotation and Scale Invariant Wafer Map Features

## Definition

These are wafer-map features designed to remain useful under wafer-map rotation and scale variation, including Radon-based, geometry-based, regional, statistical, and linear attributes in the processed Wu et al. paper.

## Why It Matters

They reduce large-scale wafer maps into compact representations for failure pattern recognition and similarity ranking.

## Used In These Papers

- [[2015 - Wafer Map Failure Pattern Recognition and Similarity Ranking for Large-Scale Data Sets]] proposes and evaluates these features on WM-811K.
