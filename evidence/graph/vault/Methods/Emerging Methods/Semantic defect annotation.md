# Semantic Defect Annotation

## Definition

Semantic defect annotation adds richer semantic labels to defect datasets so benchmark evaluation can measure finer-grained defect understanding rather than only binary anomaly detection or coarse segmentation.

## Why It Matters

Richer defect labels can expose whether a model understands defect categories, visual attributes, and localization details instead of only detecting that an image is anomalous.

## Used In These Papers

- [[2024 - Defect Spectrum A Granular Look of Large-Scale Defect Datasets with Rich Semantics]] uses semantic-abundant annotations as the central benchmark contribution.
