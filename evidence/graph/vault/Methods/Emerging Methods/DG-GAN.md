# DG-GAN

## Definition

DG-GAN is a defect-image generation method that uses progressive generation ideas, D2 adversarial loss, cyclic consistency loss, data augmentation, and self-attention to generate pseudo-defect images for downstream defect detection.

## Why It Matters

It captures a reusable technical approach for handling scarce, imbalanced, or hard-to-label defect data in industrial visual inspection.
