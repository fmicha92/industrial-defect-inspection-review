# NHD-YOLO

## Definition

NHD-YOLO is a [[YOLOv8]]-based surface-defect detector that combines shortcut feature pyramid fusion, an adaptive decoupled detection head, and selective small object copy-paste augmentation.

## Why It Matters

It targets the small-object and feature-alignment weaknesses that can reduce defect detection accuracy in industrial surface inspection.

## Used In These Papers

- [[2024 - NHD-YOLO Improved YOLOv8 Using Optimized Neck and Head]] introduces NHD-YOLO and reports NEU-DET AP improvement from 38.5 to 39.6 for the YOLOv8s/NHD-YOLOs comparison.
