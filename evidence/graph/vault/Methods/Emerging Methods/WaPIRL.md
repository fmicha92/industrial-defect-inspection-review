# WaPIRL

## Definition

Self-supervised wafer bin map representation learning framework based on noise-contrastive pretraining and supervised fine-tuning.

## Why It Matters

The linked paper uses this method as a central mechanism for industrial defect detection, anomaly detection, anomaly localization, or data-efficient inspection.

## Used In These Papers

- [[2020 - Self-Supervised Representation Learning for Wafer Bin Map Defect Pattern Classification]] uses WaPIRL for contrastive self-supervised pretraining on unlabeled [[WM-811K]] wafer bin maps before supervised fine-tuning.
