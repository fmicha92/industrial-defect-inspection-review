# Reference dataset construction

## Definition

Reference dataset construction defines a controlled dataset structure so different visual inspection algorithms can be evaluated and compared on the same material classes, defect classes, file formats, and annotations.

## Why It Matters

Comparable inspection experiments need shared data definitions. In the TILDA report, the dataset construction specifies textile surface classes, defect categories, grayscale TIFF image properties, per-defect text descriptions, and filename conventions so textile defect detection methods can be evaluated on common inputs.

## Used In These Papers

- [[1996 - TILDA Reference Dataset Report]] documents the construction of [[TILDA]] as a reference dataset for evaluating textile surface inspection algorithms.
