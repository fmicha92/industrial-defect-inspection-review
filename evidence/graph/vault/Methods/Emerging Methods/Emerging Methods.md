# Emerging Methods

Use this folder for methods, algorithms, training procedures, losses, architectures, or evaluation techniques that do not yet fit the current `Methods/` or `Methods/Models/` taxonomy. Learning paradigms belong under `Learning Paradigms/`, not here.

Promote a method when it is central to a paper, appears repeatedly, or needs a stable hub for future graph links.

## Staging Rule

Every emerging method note must link back to its source paper, a plausible stable method/model/task neighbor when available, and related emerging notes from the same paper. If the parent is unclear, set `candidate_parent: "not clear"` and explain the uncertainty in `## Related Concepts`.

Update this index with a wikilink whenever a new emerging method note is created.
