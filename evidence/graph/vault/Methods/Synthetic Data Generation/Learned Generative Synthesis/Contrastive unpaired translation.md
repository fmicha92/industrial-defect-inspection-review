# Contrastive Unpaired Translation

## Definition

Contrastive unpaired translation is an image-to-image translation method for mapping images from a source visual domain to a target visual domain without paired source-target examples.

## Why It Matters

In synthetic-to-real industrial inspection, unpaired translation can be used to reduce appearance differences between rendered training images and factory-floor images.
