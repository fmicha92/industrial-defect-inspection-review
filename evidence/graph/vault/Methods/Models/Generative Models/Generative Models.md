## Used In These Papers


- [[2014 - Generative Adversarial Nets]] introduces the [[GAN]] framework as a deep generative modeling approach trained by adversarial generator-discriminator optimization.
- [[2015 - Deep Unsupervised Learning using Nonequilibrium Thermodynamics]] introduces [[Diffusion models]] as learned reverse Markov chains for generative modeling.
- [[2020 - Denoising Diffusion Probabilistic Models]] demonstrates high-quality image synthesis with [[Diffusion models]] and a denoising objective.
- [[2025 - SeaS Few-Shot Industrial Anomaly Image Generation with Separation and Sharing Fine-Tuning]] supports few-shot anomaly generation, industrial anomaly image generation.
- [[2021 - Defect-GAN High-Fidelity Defect Synthesis for Automated Defect Inspection]] uses GAN-based controlled defect synthesis.
- [[2021 - Synthetic Image Data Augmentation for Fibre Layup Inspection Processes]] studies conditional DCGAN augmentation.
- [[2023 - A Deep-Learning-Based Approach for Aircraft Engine Defect Detection]] uses DCGAN for synthesis and Pix2Pix for deblurring.
- [[2025 - Synthetic Scientific Image Generation with VAE GAN and Diffusion Model Architectures]] compares VAEs, GANs, and diffusion models for scientific image synthesis.
