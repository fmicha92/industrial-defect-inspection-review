# DeepLabV3+

## Definition

DeepLabV3+ is a semantic segmentation architecture used to predict pixel-level class masks from images.

## Why It Matters

DeepLabV3+ provides a reusable segmentation baseline for PV-system localization from aerial imagery.

## Used In These Papers

- [[2020 - Segmentation-Based Deep-Learning Approach for Surface-Defect Detection]] compares a pretrained DeepLabV3+ baseline against the proposed [[Segmentation-decision network]] on [[KolektorSDD]].
- [[2022 - SolarDK A high-resolution urban solar panel image classification and localization dataset]] evaluates ResNet-backed DeepLabV3+ baselines for SolarDK PV-system segmentation.
- [[2023 - A benchmark dataset for defect detection and classification in electroluminescence images of PV modules using semantic segmentation]] finds DeepLabV3+ with custom class weights has the strongest average defect mIoU on [[BenchmarkELimages]].
