# FPN

## Definition

Feature Pyramid Network is a multi-scale convolutional architecture that combines high-level semantic features with lower-level spatial detail for dense prediction.

## Why It Matters

It is a common segmentation backbone for visual defect segmentation where both object context and fine defect boundaries affect mIoU.
