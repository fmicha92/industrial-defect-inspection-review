# Transformers

Transformers are neural network architectures built around attention mechanisms. Use this folder for transformer-family models across language, vision, sequence, graph, and multimodal settings.

## Typical Uses

- language and sequence modeling
- vision transformers
- encoder, decoder, and encoder-decoder architectures
- multimodal and foundation models

## Current Vault Status

[[2017 - Attention Is All You Need]] is the central architecture source for the Transformer family in this vault. Keep this folder for transformer-family papers across language, vision, sequence, graph, and multimodal inspection settings.

## Used In These Papers

- [[2017 - Attention Is All You Need]] introduces the [[Transformer]] architecture for sequence transduction.
- [[2019 - BERT Pre-training of Deep Bidirectional Transformers for Language Understanding]] uses Transformer encoders for bidirectional language representation pretraining.
- [[2023 - Conditional TransGAN-Based Data Augmentation for PCB Electronic Component Inspection]] supports PCB component inspection, generative augmentation.
- [[2024 - Benchmark for Welding Gun Fault Prediction with Multivariate Time Series Data]] benchmarks Temporal Fusion Transformer for welding-gun target-parameter forecasting.

- [[2022 - MSFT-YOLO Improved YOLOv5 Based on Transformer for Detecting Defects of Steel Surface]] supports steel surface defect detection, YOLOv5.
