# Anomaly Detection Models

## Scope

Anomaly detection models are especially relevant for industrial inspection because real defect samples are rare and incomplete.

## Common Models

- One-class SVM
- Isolation Forest
- Autoencoder-based anomaly detection
- Memory-bank methods
- Reconstruction-based methods
- Feature-distribution methods
- Teacher-student / knowledge-distillation methods
- Reverse-distillation methods
