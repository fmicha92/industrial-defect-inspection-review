# Decision Tree

## Definition

A decision tree predicts by recursively splitting feature space and assigning outputs at terminal nodes.

## Why It Matters

Random forests combine many tree predictors so that individual trees vote for a class or average a regression output.

## Used In These Papers

- [[2001 - Random Forests]] defines a random forest as a collection of tree-structured classifiers whose trees depend on independent random vectors.
