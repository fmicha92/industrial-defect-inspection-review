# Support Vector Machine

## Definition

Support vector machine is a supervised machine-learning model that learns a decision boundary between classes, often used with engineered features or pretrained embeddings.

## Why It Matters

SVMs are useful as lightweight classifiers on top of fixed feature representations, especially when datasets are small.

## Used In These Papers

- [[2023 - Cost Efficient Defect Detection in Bangle Industry Using Transfer Learning]] reports the strongest bangle classification results with SVM over ResNet50 features.
- [[2025 - Comparison of ML classifiers in automatic diagnostics of PV panels using deep image features]] reports the best PV panel classifier as a hybrid [[ResNet-18]] feature extractor with SVM classification.
- [[2023 - Automated Steel Surface Defect Detection and Classification Using a New Deep Learning-Based Approach]] uses SVM over PAR-CNN deep features and reports higher accuracy than the PAR-CNN softmax classifier.
