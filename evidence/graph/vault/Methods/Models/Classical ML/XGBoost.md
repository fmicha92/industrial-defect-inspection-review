# XGBoost

## Definition

XGBoost is a gradient-boosted decision tree model used for supervised classification or regression on tabular features.

## Why It Matters

It is a strong classical ML baseline when image models are converted into fixed feature vectors, but its performance depends on whether those features preserve task-relevant visual structure.

## Used In These Papers

- [[2025 - Comparison of ML classifiers in automatic diagnostics of PV panels using deep image features]] evaluates XGBoost on [[ResNet-18]] features with PCA for six-class PV panel defect classification, where it performs worse than SVM, Random Forest, Keras CNN, and CNN + SVM.
