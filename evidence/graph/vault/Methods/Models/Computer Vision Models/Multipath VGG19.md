# Multipath VGG19

## Definition

Multipath VGG19 is a VGG19 modification that connects early and late convolutional blocks through extra feature processing paths, then concatenates those features before classification.

## Why It Matters

It is proposed to improve feature extraction for industrial object and defect recognition across multiple public industrial image datasets.

## Used In These Papers

- [[2023 - Industrial Object and Defect Recognition Utilizing Multilevel Feature Extraction]] reports MVGG19 outperforming baseline VGG19 and achieving top performance on five of six datasets.
