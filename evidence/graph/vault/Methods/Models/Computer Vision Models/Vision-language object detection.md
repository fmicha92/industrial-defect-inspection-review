# Vision-Language Object Detection

## Definition

Vision-language object detection localizes objects using visual features and text category descriptions or phrases.

## Why It Matters

Text-image alignment enables detectors to generalize to target categories and domains with few labels, but few-shot fine-tuning can still overfit or be harmed by sparse support annotations.
