# GroundingDINO

## Definition

GroundingDINO is a grounded open-set object detection model that combines DINO-style detection with text-image grounding.

## Why It Matters

The GiPL paper uses GroundingDINO with a Swin-B backbone for RUOD and CarDD cross-domain few-shot object detection because it provides localization for underwater objects and fine-grained car damage.

## Used In These Papers

- [[2026 - GiPL Generative augmented iterative Pseudo-Labeling for Cross-Domain Few-Shot Object Detection]] uses GroundingDINO as the baseline and adapted detector for RUOD and CarDD.
