# RT-DETR

## Definition

RT-DETR is a real-time transformer-based object detection model used as a detector baseline in industrial defect detection experiments.

## Why It Matters

It provides a transformer-style detector comparison against CNN-based detectors such as YOLOv5 and YOLOv8.
