# YOLOv11

## Definition

YOLO-family object detection model used for workpiece surface defect detection in the YOLOv11 edge-computing paper.

## Why It Matters

This item supports industrial defect detection, anomaly detection, classification, segmentation, generation, or benchmark evaluation.

## Used In These Papers

- [[2025 - Workpiece Surface Defect Detection Based on YOLOv11 and Edge Computing]] trains YOLOv11 from scratch for workpiece surface defect detection, reports 85.1% mAP@0.5 with SA-GAN on NEU-DET, and converts the model to YOLOv11-RKNN for RK3568 edge deployment.
- [[2025 - Synthetic Dataset for AI-Driven Photovoltaic Fault and Damage Detection via UAV Thermal Imaging]] evaluates YOLOv11n/s/m/l/x for thermal PV panel detection and YOLOv11m/l/x for synthetic PV fault detection.
