# LeNet-5

## Definition

LeNet-5 is a convolutional neural network for handwritten digit recognition, using convolution, subsampling, fully connected layers, and an RBF output layer.

## Why It Matters

It is a canonical early CNN architecture showing that local receptive fields, weight sharing, and subsampling can improve visual document recognition.
