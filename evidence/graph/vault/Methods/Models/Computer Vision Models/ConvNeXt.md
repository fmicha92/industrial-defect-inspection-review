# ConvNeXt

## Definition

ConvNeXt is a modern convolutional neural-network architecture used as an image classifier or visual backbone.

## Why It Matters

ConvNeXt provides a strong convolutional baseline for aerial-image solar-panel classification in [[SolarDK]].

## Used In These Papers

- [[2022 - SolarDK A high-resolution urban solar panel image classification and localization dataset]] evaluates ConvNeXt for binary PV/no-PV classification and reports one of the strongest classification baselines.
