# YOLOv4

## Definition

YOLOv4 is a one-stage object detection model used as a baseline or detector family in industrial defect detection papers.

## Why It Matters

YOLOv4 provides a speed-oriented detection backbone for real-time inspection settings.

## Used In These Papers

- [[2021 - Simulation-Based Data Augmentation for Quality Inspection of Structural Adhesive]] evaluates YOLOv4-family detectors.
- [[2021 - Generative Adversarial Networks for Data Augmentation in Structural Adhesive Inspection]] trains YOLOv4-Tiny on real, synthetic-only, simulation-augmented, and GAN-augmented adhesive defect datasets.
- [[2023 - Deep Learning Based Online Metallic Surface Defect Detection Method for Wire and Arc Additive Manufacturing]] builds YOLO-attention from YOLOv4 for online WAAM defect detection.
- [[2022 - Video-Based Two-Stage Network for Optical Glass Sub-Millimeter Defect Detection]] uses a YOLOv4-style detector in both coarse and fine detection stages.
