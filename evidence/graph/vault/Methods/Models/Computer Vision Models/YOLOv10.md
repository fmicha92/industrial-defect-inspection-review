# YOLOv10

## Definition

YOLOv10 is a YOLO-family object detection model used in processed solar-cell and casting-surface defect detection papers. [[2024 - High-Precision Defect Detection in Solar Cells Using YOLOv10 Deep Learning Model]] uses the YOLOv10x variant with Compact Inverted Blocks and Partial Self-Attention for electroluminescence solar-cell defect detection.

## Why It Matters

The papers use YOLOv10 as a high-speed detector for visual defect localization. The solar-cell paper reports 98.5% mAP@0.5 and 25 FPS inference on a standard Nvidia GTX 1080.

## Used In These Papers

- [[2024 - High-Precision Defect Detection in Solar Cells Using YOLOv10 Deep Learning Model]] applies YOLOv10x to photovoltaic cell defect detection on [[EL Solar Cells Dataset]].
- [[2025 - CSDD A Benchmark Dataset for Casting Surface Defect Detection and Segmentation]] includes YOLOv10 as a CSDD detection baseline.
