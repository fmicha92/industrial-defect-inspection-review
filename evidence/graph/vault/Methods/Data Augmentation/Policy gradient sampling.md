# Policy Gradient Sampling

## Definition

Policy gradient sampling estimates gradients for sampled discrete policies. In ALADA, it is used because the candidate augmentation operations are non-differentiable.

## Used In These Papers

- [[2023 - ALADA A Lite Automatic Data Augmentation Framework for Industrial Defect Detection]] uses policy gradient sampling to update augmentation policy weights in a three-step bi-level optimization scheme.
