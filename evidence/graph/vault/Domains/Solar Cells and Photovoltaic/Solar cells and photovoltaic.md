# Solar cells and photovoltaic

## Definition

Solar cells and photovoltaic covers inspection, mapping, classification, segmentation, and device modelling for photovoltaic cells, panels, and solar PV systems. The processed papers include electroluminescence defect inspection, RGB panel-condition classification, aerial PV-system mapping, and lead-free perovskite device simulation.

## Used In These Papers

- [[2022 - Identifying Defective Solar Cells in Electroluminescence Images Using Deep Feature Representations]] supports electroluminescence images, deep feature representations.
- [[2023 - Deep-Learning-Based Automatic Detection of Photovoltaic Cell Defects in Electroluminescence Images]] supports photovoltaic cell defects, electroluminescence images.
- [[2021 - SIGAN A Novel Image Generation Method for Solar Cell Defect Segmentation and Augmentation]] supports solar cell defect segmentation, generative data augmentation.
- [[2023 - PVEL-AD A Large-Scale Open-World Dataset for Photovoltaic Cell Anomaly Detection]] introduces a large public PV EL anomaly dataset and benchmark.
- [[2022 - SolarDK A high-resolution urban solar panel image classification and localization dataset]] introduces [[SolarDK]] for aerial-image solar-panel classification and localization in Denmark.
- [[2024 - Enhanced Photovoltaic Panel Defect Detection via Adaptive Complementary Fusion in YOLO-ACF]] evaluates a YOLO-based detector for photovoltaic panel defects using data reported through the PVEL-AD repository.
- [[2026 - IncepViTH-Net for Solar Panel Fault Detection and Classification]] evaluates a hybrid Inception/transformer/harmonic-fusion classifier on public clean/faulty solar panel imagery.
- [[2025 - Lightweight Multiscale Feature Fusion Network for Solar Cell Defect Detection]] introduces solar-cell EL segmentation datasets and evaluates a lightweight segmentation network.
- [[2025 - Comparison of ML classifiers in automatic diagnostics of PV panels using deep image features]] introduces [[PV Panel Defect Dataset]] and compares classical, CNN, and hybrid CNN + SVM classifiers for RGB PV panel diagnostics.
- [[2026 - Diagnosing Shortcut Learning in CNN-Based Photovoltaic Fault Recognition from RGB Images]] audits shortcut learning and explanation faithfulness for RGB photovoltaic panel fault recognition.
- [[2021 - Comprehensive Device Modelling and Performance Analysis of MASnI3 Based Perovskite Solar Cells]] simulates lead-free perovskite solar-cell layer stacks and photovoltaic performance.
- [[2025 - Advanced Photovoltaic Module Characterization Using Image Transformers for Current-Voltage Curve Prediction From Electroluminescence Images]] predicts photovoltaic module I-V curves and electrical parameters from electroluminescence images.
- [[2020 - Infrared Solar Module Dataset for Anomaly Detection]] introduces [[InfraredSolarModules]] for infrared solar-module anomaly classification.
- [[2025 - Synthetic Dataset for AI-Driven Photovoltaic Fault and Damage Detection via UAV Thermal Imaging]] introduces a Zenodo UAV thermal PV dataset and evaluates YOLOv11 detectors for panel and synthetic fault detection.
- [[2023 - A benchmark dataset for defect detection and classification in electroluminescence images of PV modules using semantic segmentation]] introduces [[BenchmarkELimages]] for pixel-level defect segmentation in solar-cell electroluminescence images.
- [[2023 - GBH-YOLOv5 Ghost Convolution with BottleneckCSP and Tiny Target Prediction Head Incorporating YOLOv5 for PV Panel Defect Detection]] introduces [[PV-Multi-Defect]] and [[GBH-YOLOv5]] for PV panel surface-defect detection.
- [[2024 - High-Precision Defect Detection in Solar Cells Using YOLOv10 Deep Learning Model]] applies YOLOv10x to electroluminescence solar-cell defect detection on [[EL Solar Cells Dataset]].
- [[2024 - Improved Hybrid Solar Cell Defect Detection Using GANs and Weighted Classification]] supports binary solar-cell defect classification with WGAN-GP augmentation on [[ELPV Dataset]] and a confidential custom EL dataset.
- [[2025 - Advanced deep learning modeling to enhance detection of defective photovoltaic cells in electroluminescence images]] supports GAN-oversampled PV EL defect classification with CNN backbones and validation-threshold tuning.
- [[2025 - Comparative Deep Learning for RGB-Based PV Surface Fault Classification Using ResNet50 and EfficientNetB0]] supports RGB PV surface fault classification on [[PV Panel Defect Dataset]] with training-data augmentation.
- [[2024 - Deep Learning for Solar Panels Defect Classification Using Data Augmentation Strategies]] supports binary solar panel defect classification and compares classical augmentation configurations.
- [[2023 - A Data Generation Method with Dual Discriminators and Regularization for Surface Defect Detection Under Limited Data]] constructs [[SAPF]], a solar aluminum profile frame surface-defect dataset for YOLO-v5 and YOLO-v8 augmentation experiments.
