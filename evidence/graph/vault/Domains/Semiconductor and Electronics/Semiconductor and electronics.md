# Semiconductor and electronics

## Definition

Semiconductor and electronics inspection covers defect detection, defect classification, and visual fault inspection for wafers, wafer bin maps, printed circuit boards, and electronic assemblies. The processed papers use this domain for wafer-map defect recognition, PCB component inspection, PCB surface defects, and semiconductor manufacturing fault inspection.

- [[2015 - Wafer Map Failure Pattern Recognition and Similarity Ranking for Large-Scale Data Sets]] introduces WM-811K for wafer-map failure pattern recognition and similarity ranking in semiconductor fabrication.

- [[2020 - Deformable Convolutional Networks for Efficient Mixed-Type Wafer Defect Pattern Recognition]] supports mixed-type wafer defects, deformable convolution.

- [[2024 - A Dataset for Deep Learning Based Detection of Printed Circuit Board Surface Defect]] introduces [[DsPCBSD+]] for PCB surface-defect object detection using real AOI images from inner and outer layers after etching.

- [[2025 - Simulation of semiconductor wafer dicing induced faults on chips]] evaluates [[Spline-based wafer dicing fault synthesis]] for chip-level visual inspection, improving ResNet152V2 macro F1 from 93.80% on original wafer data to 95.14% on composite wafer data.

- [[2021 - Multiple Granularities Generative Adversarial Network for Recognition of Wafer Map Defects]] supports wafer map defect recognition, class imbalance.

- [[2020 - Self-Supervised Representation Learning for Wafer Bin Map Defect Pattern Classification]] supports wafer bin map classification, self-supervised learning.

- [[2022 - Semi-Supervised Defect Detection Method with Data-Expanding Strategy for PCB Quality Inspection]] supports PCB defect detection, semi-supervised learning.
- [[2023 - SSGD A Smartphone Screen Glass Dataset for Defect Detection]] supports smartphone touch-screen glass defect localization with public high-resolution images.
- [[2018 - Object Detection using Domain Randomization and Generative Adversarial Refinement of Synthetic Images]] uses synthetic and GAN-refined images for detecting industrial electric parts.
- [[Heat Sink Surface Defect Dataset]] supports segmentation of gold-plated tungsten-copper alloy heat sink surface scratches and stains, with collection attributed to the Institute of Semiconductors, Chinese Academy of Sciences.
- [[2022 - Surface Defect Detection of Heat Sink Based on Lightweight Fully Convolutional Network]] supports automated inspection of gold-plated tungsten-copper alloy heat sinks used for chip heat dissipation.
- [[2025 - Segmentation-Enhanced Overlapped Defect Identification for Multipatterns Wafer Maps]] supports overlapped wafer-map defect detection and segmentation on [[MixedWM38]].

- [[2020 - Using GAN to Improve CNN Performance of Wafer Map Defect Type Classification]] supports wafer map classification with GAN-generated training samples on [[WM-811K]].
- [[2024 - Wafer Map Defect Classification Using Autoencoder-Based Data Augmentation and Convolutional Neural Network]] supports semiconductor wafer-map defect classification with autoencoder-generated training samples on [[WM-811K]].
- [[2025 - Sample-Imbalanced Wafer Map Defects Classification Based on Jacobian Regularized Generative Adversarial Network]] supports wafer-map defect classification with [[JRGAN]] augmentation on [[WM-811K]] and [[MixedWM38]].
- [[2023 - DPG-DT Differentially Private Generative Digital Twin for Imbalanced Learning in Industrial IoT]] supports private synthetic generation for [[DeepPCB]] and industrial imbalanced learning.
- [[2020 - Weakly-Supervised Defect Segmentation on Periodic Textures Using CycleGAN]] supports weakly supervised segmentation of private SEM semiconductor periodic-texture defects using synthetic defect and non-defect image generation.
