# Textile and fiber inspection

## Definition

Textile and fiber inspection covers visual quality-control tasks for fabrics, fiber layup, and related textile materials, including defect detection, defect classification, and production-line inspection.

## Represented Papers

- [[2021 - Synthetic Image Data Augmentation for Fibre Layup Inspection Processes]] studies synthetic image augmentation for automated fiber placement inspection.
- [[2024 - Conditional image-to-image translation generative adversarial network cGAN for fabric defect data augmentation]] uses AITEX fabric images and masks for cGAN-based textile defect synthesis.
- [[2022 - Deep Adversarial Data Augmentation for Fabric Defect Classification With Scarce Defect Data]] uses ZJU-Leaper for scarce-data fabric defect classification with DefectTransfer.
- [[2022 - Data Augmentation Method for Fabric Defect Detection]] uses geometric and GAN-based augmentation for fabric defect detection.
- [[2022 - Fabric Defect Segmentation System Based on a Lightweight GAN for Industrial Internet of Things]] uses AITEX and enterprise fabric data for GAN repair-based segmentation.
- [[2022 - Defect Detection in the Textile Industry Using Image-Based Machine Learning Methods]] reviews image-based machine learning and deep learning methods for automated textile defect inspection.
- [[2025 - AI-driven fabric classification]] documents microscopy-image recording for [[DME Fabric Defect Detection Dataset]] and uses PSRT50 for real-time fabric classification on Raspberry Pi 4.
- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] proposes [[STDAN]] for self-supervised textile anomaly detection and evaluates it on [[FD_Dataset]], [[FabricSpotDefect]], and [[Lusitano]].
- [[2024 - Defect detection in textile manufacturing Improving findings using YOLOv5 versions]] evaluates YOLOv5 variants on AITEX-derived textile defect detection with native augmentation and transfer learning.

## Used In These Papers

- [[2019 - A Public Fabric Database for Defect Detection Methods and Results]] introduces a public annotated benchmark of real production fabric images with defect labels and segmentation masks.
- [[2021 - ZJU-Leaper A Benchmark Dataset for Fabric Defect Detection and a Comparative Study]] introduces a large fabric defect dataset and benchmark for textile manufacturing inspection.
- [[2024 - A Novel Dataset for Fabric Defect Detection Bridging Gaps in Anomaly Detection]] introduces a factory-collected fabric anomaly detection dataset from Portugal.
- [[2025 - Dataset for Defect Detection in Textile Manufacturing]] introduces public Batavia and Sarga woven fabric images with case/control patch labels.
- [[2024 - FabricSpotDefect An Annotated Dataset for Identifying Spot Defects in Different Fabric Types]] introduces a public fabric spot-defect dataset with bounding-box and polygon annotations.
- [[2024 - Conditional image-to-image translation generative adversarial network cGAN for fabric defect data augmentation]] supports AITEX as a textile synthesis benchmark.
- [[2022 - Deep Adversarial Data Augmentation for Fabric Defect Classification With Scarce Defect Data]] supports ZJU-Leaper as a public benchmark for scarce-defect augmentation.
- [[2022 - Deep Adversarial Data Augmentation for Fabric Defect Classification With Scarce Defect Data]] also introduces [[LaceCls]] as an author-collected lace production-line dataset for scarce-defect augmentation.
- [[2025 - Artificial Intelligence Driving Innovation in Textile Defect Detection]] summarizes public textile defect datasets, including AITEX, Lusitano, ZJU-Leaper, and TILDA.
- [[1996 - TILDA Reference Dataset Report]] documents the TILDA textile texture database for evaluating visual inspection methods for textile surface defects.
- [[2022 - Defect Detection in the Textile Industry Using Image-Based Machine Learning Methods]] summarizes textile defect categories, AOI trade-offs, reviewed metrics, and recent ML/DL methods for fabric inspection.
- [[2025 - AI-driven fabric classification]] supports the recording process for [[DME Fabric Defect Detection Dataset]] and reports PSO-tuned ResNet50 experiments on fabric microscopy images.
- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] supports self-supervised fabric anomaly detection with feature-level defect amplification and reports FD_Dataset evaluation results.
- [[2024 - A Unified Anomaly Synthesis Strategy with Gradient Ascent for Industrial Anomaly Detection and Localization]] evaluates GLASS on the [[Woven fabric defect dataset]] and reports 100.0 image-level AUROC, 98.9 pixel-level AUROC, and 94.9 PRO for GLASS-j.
- [[2020 - Weakly-Supervised Defect Segmentation on Periodic Textures Using CycleGAN]] uses TILDA textile periodic textures as a cross-domain evaluation case for weakly supervised CycleGAN-based defect segmentation.
- [[2024 - Defect detection in textile manufacturing Improving findings using YOLOv5 versions]] supports textile defect object detection on [[AITEX]] with YOLOv5 variants and data augmentation.
- [[2025 - Blind super-resolution network based on local fuzzy discriminative loss for fabric data augmentation]] uses improved Real-ESRGAN super-resolution as fabric defect data augmentation for downstream YOLOv5n detection.
