# Underwater Object Detection

## Definition

Underwater object detection localizes objects in underwater imagery, where visibility can be affected by low contrast, color distortion, and turbidity.

## Why It Matters

The GiPL paper treats underwater imagery as a cross-domain target setting where detector adaptation must handle substantial appearance shift from common detection data.
