# Emerging Domains

Use this folder for new application domains, industries, materials, sensor contexts, or deployment settings that do not yet fit the stable `Domains/` taxonomy.

Promote a domain when it appears across multiple papers, becomes a recurring retrieval path, or clearly deserves a stable folder under `Domains/`.

## Staging Rule

Every emerging domain note must link back to its source paper, a plausible stable domain/task/dataset neighbor when available, and related emerging notes from the same paper. If the parent is unclear, set `candidate_parent: "not clear"` and explain the uncertainty in `## Related Concepts`.

Update this index with a wikilink whenever a new emerging domain note is created.
