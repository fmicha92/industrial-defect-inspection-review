# Document Analysis

## Definition

Document analysis covers visual recognition of characters, digits, words, and structured fields in document images.

## Why It Matters

The document-recognition papers use CNNs and trainable structured systems to classify handwritten digits and read document fields.

## Related Datasets

### Public

- [[MNIST]]

## Used In These Papers

- [[1998 - Gradient-Based Learning Applied to Document Recognition]] develops LeNet-5 and graph transformer networks for document recognition.
- [[2003 - Best Practices for Convolutional Neural Networks Applied to Visual Document Analysis]] evaluates CNN training practices on MNIST.
- [[2015 - Adam A Method for Stochastic Optimization]] uses MNIST logistic regression and multilayer neural-network training to compare optimizers.
