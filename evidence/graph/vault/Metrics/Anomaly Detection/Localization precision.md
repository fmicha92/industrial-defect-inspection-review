# Localization Precision

## Definition

Localization precision measures how accurately predicted anomaly heatmap regions align with ground-truth defect regions. In [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]], it is reported as a pixel-level defect-localization metric for STDAN.

## Direction

Higher is better.

## Used In These Papers

- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] reports 91% localization precision for STDAN.
