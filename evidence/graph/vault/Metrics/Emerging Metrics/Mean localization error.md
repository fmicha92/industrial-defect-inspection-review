# Mean Localization Error

## Definition

Mean localization error reports the average distance between predicted and ground-truth object positions.

## Used In These Papers

- [[2017 - Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World]] reports object-localization errors in centimeters for real tabletop test images.
