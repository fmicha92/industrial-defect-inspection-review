# Endpoint Error

## Definition

Endpoint error is the reported pixel or vector-distance error used for dense flow, disparity, or scene-flow outputs in the cited paper.

## Used In These Papers

- [[2016 - A Large Dataset to Train Convolutional Networks for Disparity Optical Flow and Scene Flow Estimation]] reports endpoint error for optical flow, disparity, and disparity change.
