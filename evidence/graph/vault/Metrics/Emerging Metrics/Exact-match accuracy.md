# Exact-Match Accuracy

## Definition

Exact-match accuracy counts an output as correct only when the full predicted sequence exactly matches the target sequence.

## Used In These Papers

- [[2018 - Generalization without Systematicity On the Compositional Skills of Sequence-to-Sequence Recurrent Networks]] reports exact sequence accuracy on SCAN splits.
