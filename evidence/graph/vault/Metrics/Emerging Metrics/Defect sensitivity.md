# Defect Sensitivity

## Definition

Defect sensitivity measures the proportion of actual defects detected, using TP / (TP + FN). In [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]], it is used to assess STDAN's ability to detect weak, subtle, or low-contrast fabric defects.

## Direction

Higher is better.

## Used In These Papers

- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] reports 97% defect sensitivity for STDAN.
