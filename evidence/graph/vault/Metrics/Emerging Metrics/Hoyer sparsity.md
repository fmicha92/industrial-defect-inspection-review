# Hoyer Sparsity

## Definition

Hoyer sparsity measures compactness in an attribution or relevance map using an `l1/l2`-style ratio.

## Direction

Higher means more compact relevance, but compact maps can still be mislocalized.

- [[2026 - Diagnosing Shortcut Learning in CNN-Based Photovoltaic Fault Recognition from RGB Images]] reports Hoyer sparsity for occlusion sensitivity maps.
