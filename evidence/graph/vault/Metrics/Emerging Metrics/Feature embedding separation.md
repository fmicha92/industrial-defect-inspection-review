# Feature Embedding Separation

## Definition

Feature embedding separation measures the distance between normal and defect feature centroids relative to their dispersions. In [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]], it is used to assess how clearly STDAN separates normal and anomalous fabric representations.

## Direction

Higher is better.

## Used In These Papers

- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] reports feature embedding separation of 1.99 for STDAN.
