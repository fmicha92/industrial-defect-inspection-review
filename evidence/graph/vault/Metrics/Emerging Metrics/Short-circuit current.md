# Short-Circuit Current

## Definition

Short-circuit current is the current produced by a photovoltaic module when the terminal voltage is zero under the measurement conditions.

## Direction

Higher current is generally better when comparing modules under the same irradiance, temperature, and module design context.

## Used In These Papers

- [[2025 - Advanced Photovoltaic Module Characterization Using Image Transformers for Current-Voltage Curve Prediction From Electroluminescence Images]] evaluates short-circuit current derived from predicted I-V curves and reports mean error below 1%.
