# Maximum Power Point

## Definition

Maximum power point is the point on a photovoltaic module's I-V curve where electrical output power is maximized.

## Direction

Higher maximum power is generally better when comparing modules under the same measurement conditions.

## Used In These Papers

- [[2025 - Advanced Photovoltaic Module Characterization Using Image Transformers for Current-Voltage Curve Prediction From Electroluminescence Images]] evaluates maximum power point derived from predicted I-V curves and reports mean error below 1%.
