# Gaze estimation error

## Definition

Gaze estimation error measures the angular difference between predicted and ground-truth gaze direction.

## Direction

Lower is better.

## Used In These Papers

- [[2017 - Learning from Simulated and Unsupervised Images through Adversarial Training]] reports mean eye-gaze estimation error in degrees on MPIIGaze.
