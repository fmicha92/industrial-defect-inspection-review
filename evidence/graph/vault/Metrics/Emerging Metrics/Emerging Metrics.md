# Emerging Metrics

Use this folder for metrics that do not yet fit the stable metric families.

## Staging Rule

Create an emerging metric note when a paper uses a metric whose family, direction, unit, or interpretation is unclear. Include `status: emerging`, `concept_type: metric`, `candidate_parent`, `source_papers`, `evidence_count`, and the exact metric name from the source.

Every emerging metric note must link back to its source paper, a plausible stable metric family or task neighbor when available, and related emerging notes from the same paper. If the parent is unclear, set `candidate_parent: "not clear"` and explain the uncertainty in `## Related Concepts`.

Promote a metric into `Metrics/<metric-family>/` when its task context, direction, unit, and interpretation are clear enough to reuse.

Update this index with a wikilink whenever a new emerging metric note is created.
