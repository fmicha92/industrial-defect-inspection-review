# Exact Match

## Definition

Exact match is a question-answering metric that requires the predicted answer string to exactly match the reference answer. Higher is better.

## Used In These Papers

- [[2019 - BERT Pre-training of Deep Bidirectional Transformers for Language Understanding]] reports SQuAD exact match alongside F1.
