# False Acceptance Rate

## Definition

False acceptance rate measures accepted defective cases or unpredicted negative samples according to the paper-specific definition. Lower values indicate fewer defective products passing inspection.

## Used In These Papers

- [[2024 - Glass Defect Detection with Improved Data Augmentation under Total Reflection Lighting]] reports FAR by defect class and a 1.27% overall false acceptance rate in the abstract.
