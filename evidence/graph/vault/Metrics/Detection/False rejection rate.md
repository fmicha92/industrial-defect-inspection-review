# False Rejection Rate

## Definition

False rejection rate measures good or positive samples rejected by the inspection model according to the paper-specific definition. Lower values indicate fewer unnecessary rejections.

## Used In These Papers

- [[2024 - Glass Defect Detection with Improved Data Augmentation under Total Reflection Lighting]] reports FRR by defect class and a 2.47% overall false rejection rate in the abstract.
