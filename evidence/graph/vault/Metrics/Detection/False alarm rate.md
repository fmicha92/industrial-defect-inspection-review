# False Alarm Rate

## Definition

False alarm rate measures false detections among defect-free samples in a defect detection evaluation.

## Direction

Lower is better.

## Used In These Papers

- [[2019 - A Public Fabric Database for Defect Detection Methods and Results]] reports false alarm rates of 2.90% for test 1 and 11.4% for test 2 on 140 defect-free fabric images.
