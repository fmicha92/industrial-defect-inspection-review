# Defect Detection Error Rate

## Definition

Defect detection error rate measures the relative difference between detected defect areas and actual defect areas. In the HRIPCB paper, Pd is `(detected defect areas - actual defect areas) / actual defect areas x 100%`.

## Direction

Lower is better.

## Used In These Papers

- [[2020 - HRIPCB a Challenging Dataset for PCB Defects Detection and Classification]] reports 0% error for missing hole, short, spur, and spurious copper, and 0.2% for mouse bite and open circuit.
