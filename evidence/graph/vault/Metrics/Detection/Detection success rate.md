# Detection Success Rate

## Definition

Detection success rate measures correctly detected samples divided by all evaluated defective and defect-free samples. In fabric defect detection, Silvestre-Blanes et al. treat it as overall detection accuracy.

## Direction

Higher is better.

## Used In These Papers

- [[2019 - A Public Fabric Database for Defect Detection Methods and Results]] reports DSR values of 88.98% for test 1 and 87.76% for test 2 on the public fabric database.
