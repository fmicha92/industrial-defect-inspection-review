# Detection Rate

## Definition

Detection rate measures the share of defective samples correctly detected. Silvestre-Blanes et al. also refer to this quantity as sensitivity for fabric defect detection.

## Direction

Higher is better.

## Used In These Papers

- [[2019 - A Public Fabric Database for Defect Detection Methods and Results]] reports detection rate values of 82/105 = 78.10% for test 1 and 91/105 = 86.67% for test 2.
