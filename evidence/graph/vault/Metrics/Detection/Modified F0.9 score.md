# Modified F0.9 Score

## Definition

Modified F0.9 score is a source-defined detection metric in [[2024 - Open Stamped Parts Dataset]] that combines precision with modified recall using beta = 0.9, giving more weight to precision than recall.

## Direction

Higher is better.

## Used In These Papers

- [[2024 - Open Stamped Parts Dataset]] uses modified F0.9 score as the primary model-selection metric for stamped-hole detection under missing-hole risk.
