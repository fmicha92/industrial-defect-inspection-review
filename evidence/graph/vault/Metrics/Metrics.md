# Metrics

Metrics define how a paper measures performance. Track the metric name, unit, direction, dataset/task context, and reported value when available.

## Categories

- [[Classification metrics]]
- [[Detection metrics]]

## Routing Rule

Use stable metric notes when the metric family, direction, and interpretation are clear. Use [[Emerging Metrics]] when a metric is paper-specific, ambiguous, or not yet understood well enough to classify.
