# CLIPScore

## Definition

CLIPScore measures semantic alignment between an image and a text prompt in a joint image-text embedding space.

## Direction

Higher is better.

## Used In These Papers

- [[2025 - Synthetic Scientific Image Generation with VAE GAN and Diffusion Model Architectures]] uses CLIPScore for prompt-conditioned scientific image generation and reports that it can be poorly aligned with scientific image domains.
