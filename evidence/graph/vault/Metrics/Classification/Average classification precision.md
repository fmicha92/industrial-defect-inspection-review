# Average Classification Precision

## Definition

Average classification precision is the mean of per-class classification precision rates across the evaluated defect types. In the HRIPCB paper, per-class precision rate is the correctly predicted number of a defect type divided by the actual number of defects of that type.

## Direction

Higher is better.

## Used In These Papers

- [[2020 - HRIPCB a Challenging Dataset for PCB Defects Detection and Classification]] reports APc values of 97.74% on test data and 99.40% on all samples.
