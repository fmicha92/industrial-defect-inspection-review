# Top-1 Error

## Definition

Top-1 error is the percentage of classification examples where the model's highest-scoring class is incorrect. Lower is better.

## Used In These Papers

- [[2016 - Deep Residual Learning for Image Recognition]] reports ImageNet validation top-1 error for plain networks and ResNets.
