# Matthews Correlation Coefficient

## Definition

Matthews correlation coefficient is a classification metric computed from true positives, true negatives, false positives, and false negatives. It is commonly used when class imbalance makes accuracy less informative.

## Direction

Higher is better.

## Used In These Datasets

- [[Bosch Production Line Performance]] used Matthews correlation coefficient as the Kaggle competition evaluation metric.

## Used In These Papers

- [[2016 - Predict Failures in Production Lines A Two-stage Approach with Clustering and Supervised Learning]] uses MCC as the primary performance metric for the imbalanced Bosch failure-prediction task and reports total MCC 0.211.
