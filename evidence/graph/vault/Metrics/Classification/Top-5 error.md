# Top-5 Error

## Definition

Top-5 error is the percentage of classification examples where the correct class is absent from the model's five highest-scoring classes. Lower is better.

## Used In These Papers

- [[2016 - Deep Residual Learning for Image Recognition]] reports a 3.57% ImageNet test-set top-5 error for the residual-network ensemble.
