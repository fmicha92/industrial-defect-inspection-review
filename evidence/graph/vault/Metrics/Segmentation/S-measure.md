# S-Measure

## Definition

S-measure is a salient object detection metric for evaluating foreground maps.

## Direction

Higher is better.

## Used In These Papers

- [[2023 - CarDD A New Dataset for Vision-Based Car Damage Detection]] reports PoolNet as the best S-measure model on [[CarDD benchmark]] with Sm 0.811.
