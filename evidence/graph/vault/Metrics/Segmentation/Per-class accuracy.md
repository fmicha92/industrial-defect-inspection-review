# Per-Class Accuracy

## Definition

Per-class accuracy averages segmentation accuracy across classes, reducing the dominance of large frequent classes.

## Used In These Papers

- [[2016 - The SYNTHIA Dataset A Large Collection of Synthetic Images for Semantic Segmentation of Urban Scenes]] reports average per-class accuracy improvements when SYNTHIA is added to real segmentation data.
