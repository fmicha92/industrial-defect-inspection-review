# F-Measure

## Definition

F-measure is a salient object detection metric reported for binary foreground maps.

## Direction

Higher is better.

## Used In These Papers

- [[2020 - Segmentation-Based Deep-Learning Approach for Surface-Defect Detection]] uses the best F-measure threshold to report false positives and false negatives on [[KolektorSDD]].
- [[2020 - Surface Defect Saliency of Magnetic Tile]] reports F-measure with beta squared equal to 0.3 for magnetic-tile surface-defect saliency on [[Magnetic Tile Defects]].
- [[2023 - CarDD A New Dataset for Vision-Based Car Damage Detection]] reports SGL-KRN Fβ of 0.791 on [[CarDD benchmark]].
