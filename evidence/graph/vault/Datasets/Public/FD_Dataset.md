# FD_Dataset

## Definition

Fabric Defects Object Detection Dataset is a public Figshare textile inspection dataset containing colored-fabric defect images. It contains 720 images across four defect types: Oil, Hole, Cutting, and Crack, with approximately 180 images per type.

## Why It Matters

The dataset supports [[Textile defect detection]], [[Defect classification]], and [[Defect segmentation]] research for computer vision, image processing, deep learning, and textile manufacturing inspection. It includes a MATLAB label file for object detection workflows and a YOLO-oriented organization for training, validation, and testing.

## Used In These Papers

- Introducing paper: not reported.
- [[2026 - Texture Conditioned GAN Based Self Supervised Framework for Fabric Defect Detection]] evaluates [[STDAN]] on FD_Dataset and reports 97.56% AUC, 95.91% precision, 94.88% recall, and 95.39% F1-score.
