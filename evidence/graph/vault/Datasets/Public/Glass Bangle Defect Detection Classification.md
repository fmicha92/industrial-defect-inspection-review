# Glass Bangle Defect Detection Classification

## Definition

Glass Bangle Defect Detection Classification is a public Kaggle image-classification dataset for glass bangle quality inspection. It contains human-labeled images collected from a bangle factory and grouped into three quality classes.

## Why It Matters

The dataset supports [[Glass bangle defect classification]] in a manufacturing setting where bangles must be round, intact, and visibly defect-free before shipping. It adds a classification-oriented glass product inspection source to the graph, complementing object-detection datasets for aircraft glass, laminated glass, smartphone screen glass, optical glass, and glass containers.

## Used In These Papers

- [[2023 - Cost Efficient Defect Detection in Bangle Industry Using Transfer Learning]] reports a transfer-learning approach for bangle defect detection using the three bangle quality classes.

## Dataset Details

- Domain: [[Glass inspection]].
- Task: [[Glass bangle defect classification]].
- Object type: glass bangles.
- Images: 1080 total.
- Source setting: images collected from a bangle factory.
- Labeling: human-labeled.
- Classes: broken, defected, and good.
- Defect examples: broken bangles, visible defects, and acceptable bangles.
