# DME Fabric Defect Detection Dataset

## Definition

DME Fabric Defect Detection Dataset is a public Mendeley Data textile inspection dataset published as `20250129_Fabric_defects`. The host record describes it as an industrial microscopy image collection for automated fabric defect detection and classification, with real textile defects captured under controlled acquisition conditions.

## Why It Matters

The dataset supports [[Textile defect detection]] and [[Defect classification]] research on real textile defects collected under controlled acquisition conditions. It is positioned for computer vision, deep learning, industrial inspection, and evaluation of CNN-based and hybrid architectures.

## Used In These Papers

- [[2025 - AI-driven fabric classification]] documents the dataset recording process and uses the resulting microscopy images to train and evaluate PSRT50 for real-time fabric classification.
