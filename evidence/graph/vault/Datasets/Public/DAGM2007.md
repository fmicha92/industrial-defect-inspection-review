# DAGM2007

## Definition

DAGM2007 is a synthetic benchmark corpus for weakly supervised industrial optical inspection on statistically textured surfaces. It was created for the DAGM 2007 competition and contains grayscale texture images with non-defective and defective examples plus weak elliptical defect labels.

## Why It Matters

It supports surface-defect detection and classification experiments where algorithms must learn from weak labels and adapt to unknown texture and defect characteristics. Its synthetic multi-texture design makes it a reusable benchmark for [[Multi-industry anomaly detection]] rather than a single-material industrial dataset.

## Dataset Details

- Domain: [[Multi-industry anomaly detection]].
- Task: [[Surface defect detection]] and defect/non-defect classification under weak supervision.
- Modality: grayscale 8-bit PNG texture images.
- Dataset structure: ten artificial texture datasets; the first six are development datasets and the remaining four are competition datasets.
- Development datasets: each has 1,000 non-defective and 150 defective images.
- Competition datasets: each has 2,000 non-defective and 300 defective images.
- Zenodo files: ten class ZIP archives, one per texture class, totaling about 2.9 GB.
- Labels: defective images include a separate grayscale label image; ellipse masks roughly indicate the defective area.
- Splits: each dataset is split randomly into equally sized training and testing subsets.
- Source organization: metadata is stored in `Labels.txt` inside each `Label` folder.
