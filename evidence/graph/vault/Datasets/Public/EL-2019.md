# EL-2019

## Definition

EL-2019 is a solar-cell electroluminescence image dataset for crack, finger-interruption, and defect-free classes. The SIGAN paper reports 260 defective images and 280 defect-free images, collected from multicrystalline solar-cell manufacturing imagery.

## Why It Matters

EL-2019 supports solar-cell defect segmentation, generative defect-image evaluation, and data augmentation experiments in [[Solar cells and photovoltaic]] inspection.

## Used In These Papers

- [[2021 - SIGAN A Novel Image Generation Method for Solar Cell Defect Segmentation and Augmentation]] introduces EL-2019 and evaluates segmentation, generation quality, and classification augmentation on it.

## Dataset Details

- Hosting source: [GitHub](https://github.com/binyisu/EL-2019). The README available from the host page only gives the dataset title; the substantive metadata below comes from the SIGAN paper.
- Introducing paper: [[2021 - SIGAN A Novel Image Generation Method for Solar Cell Defect Segmentation and Augmentation]].
- Collection: multicrystalline solar-cell EL images collected during manufacturing with a near-infrared WP-US146 camera using a SONY ICX825 chip.
- Raw imagery: 1024 x 1024 pixels, cropped into 128 x 128 patches for the reported dataset.
- Classes: crack, finger interruption, and defect-free.
- Size: 540 images total; 280 defect-free and 260 defective images, with 130 crack and 130 finger-interruption images.
- Split reported for segmentation/generation: train contains 200 defect-free, 50 crack, and 50 finger-interruption images; test contains 80 defect-free, 80 crack, and 80 finger-interruption images.
- License: not reported by the paper or the minimal GitHub README checked.
