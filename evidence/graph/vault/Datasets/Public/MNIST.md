# MNIST

## Definition

MNIST is a handwritten digit recognition dataset with normalized digit images.

## Dataset Details

- Size reported by LeCun et al.: 60,000 training images and 10,000 test images.
- Image format: original characters normalized to 20x20 while preserving aspect ratio and centered in 28x28 images; LeNet-5 uses centered 32x32 inputs.
- Task: [[Handwritten digit recognition]].

## Related Papers

- [[1998 - Gradient-Based Learning Applied to Document Recognition]] reports LeNet-5 results on MNIST.
- [[2003 - Best Practices for Convolutional Neural Networks Applied to Visual Document Analysis]] evaluates CNNs and elastic distortions on MNIST.
