# WM-811K

## Definition

WM-811K is a public wafer-map dataset introduced as 811,457 real-world wafer maps collected from semiconductor fabrication, with roughly 20% manually labeled in the papers.

## Dataset Details

- Hosting source: [Kaggle](https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map/data).
- Kaggle title: `WM-811K wafer map`.
- Kaggle owner: QINGYI.
- Kaggle access status: public; Kaggle metadata reports `isPrivate: false`.
- Kaggle license: CC0: Public Domain.
- Kaggle version: 1, initial release, last updated 2018-02-26.
- Kaggle size: 2,095,505,977 bytes.
- MIR Lab note: the introducing paper reports the MIR Lab public dataset page as the dataset source; keep this as the historical/original source context even though Kaggle is now recorded as the hosting source.

## Why It Matters

It is a recurring benchmark for wafer map failure pattern recognition, deep wafer-map classification, and semi-supervised wafer defect labeling.

## Used In These Papers





- [[2025 - Wafer Map Defect Classification Using Deep Learning Framework with Data Augmentation on Imbalance Datasets]] reports 811,457 WM-811K wafer maps, uses the 25,519 patterned subset plus None class for imbalanced classification, and improves MobileNetV2-style classification from 84.25% to 93.01% F1-score with [[G2LGAN]].
- [[2024 - Wafer Map Defect Classification Using Autoencoder-Based Data Augmentation and Convolutional Neural Network]] uses the eight patterned WM-811K defect classes, applies a 4:1 train/test split, augments each class to 10,000 samples with autoencoder latent-noise reconstruction, and reports 98.56% CNN-AUG accuracy.
- [[2025 - Sample-Imbalanced Wafer Map Defects Classification Based on Jacobian Regularized Generative Adversarial Network]] uses MIR-WM811K labeled wafer maps, balances minority classes with [[JRGAN]], and reports 97.24% ResNet-18 accuracy.
- [[2020 - Deformable Convolutional Networks for Efficient Mixed-Type Wafer Defect Pattern Recognition]] supports mixed-type wafer defects, deformable convolution.
- [[2025 - Sample-Imbalanced Wafer Map Defects Classification Based on Jacobian Regularized Generative Adversarial Network]] supports class imbalance, wafer map defect classification.
- [[2024 - Wafer Map Defect Classification Using Autoencoder-Based Data Augmentation and Convolutional Neural Network]] supports wafer map defect classification, class imbalance.
- [[2015 - Wafer Map Failure Pattern Recognition and Similarity Ranking for Large-Scale Data Sets]] introduces the dataset and evaluates WMFPR/WMSR.
- [[2019 - Classification of Wafer Maps Defect Based on Deep Learning Methods With Small Amount of Data]] uses WM-811K for isolated final testing.
- [[2020 - A Light-Weight Neural Network for Wafer Map Classification Based on Data Augmentation]] uses WM-811K as the open wafer-map dataset.
- [[2022 - Wafer Defect Pattern Labeling and Recognition Using Semi-Supervised Learning]] validates semi-supervised labeling on WM-811K.
- [[2023 - Wafer Map Defect Patterns Classification Based on a Lightweight Network and Data Augmentation]] uses WM-811K for wafer-map defect pattern classification with data augmentation.
- [[2025 - A Framework for Detecting Unknown Defect Patterns on Wafer Bin Maps Using Active Learning]] uses wafer bin map data in an active-learning setting for unknown defect pattern detection.
- [[2021 - Multiple Granularities Generative Adversarial Network for Recognition of Wafer Map Defects]] uses a 22,418-image subset of WM-811K with one normal pattern and eight defect patterns to evaluate MGGAN data augmentation and ResNet101 wafer-map recognition.
