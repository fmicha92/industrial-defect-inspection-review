# Batavia and Sarga woven fabric images

## Definition

Batavia and Sarga woven fabric images is a public textile inspection dataset introduced by [[2025 - Dataset for Defect Detection in Textile Manufacturing]]. It contains original grayscale images and cropped case/control patches from Batavia and Sarga woven fabrics collected at Textil Santanderina in Spain.

## Why It Matters

The dataset supports [[Textile defect detection]] research with labeled fabric patches from two woven fabric types. It is useful for experiments on weave inconsistencies, colour variations, and surface irregularities, especially where researchers need real textile manufacturing imagery rather than synthetic examples.

## Used In These Papers

- [[2025 - Dataset for Defect Detection in Textile Manufacturing]] introduces the dataset, describes the imaging system, and reports the case/control patch organization.

## Dataset Details

- Domain: [[Textile and fiber inspection]].
- Task: [[Textile defect detection]].
- Source: Textil Santanderina, Cabezón de la Sal, Cantabria, Spain.
- Collection period: November 2022.
- Image modality: grayscale PNG fabric images.
- Original image size: 2048 x 696 pixels.
- Patch size: 365 x 365 pixels.
- Batavia originals: 2755 images.
- Batavia patches: 8782 case patches and 19,911 control patches.
- Sarga originals: 1548 images.
- Sarga patches: 173 case patches and 18,403 control patches.
- Labels: CSV metadata records image names, patch names, operator labels, and ground-truth labels where 0 means no defect and 1 means defect.
- Artifact: https://doi.org/10.36443/10259/9965.
- License: dataset license not separately reported in the extracted text; the article is CC BY-NC.
