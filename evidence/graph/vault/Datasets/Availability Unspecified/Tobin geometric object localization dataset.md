# Tobin Geometric Object Localization Dataset

## Definition

The Tobin geometric object localization dataset is the real and simulated tabletop object-localization setup used to evaluate domain randomization for robotic transfer.

## Dataset Details

- Availability: not reported.
- Real test set: 480 webcam images, 60 per object across eight geometric objects.
- Test conditions: object only, distractor objects, and partial occlusion.
- Labels: Cartesian object center positions measured with a 1 mm tabletop grid.

## Related Papers

- [[2017 - Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World]] uses this setup to evaluate simulated-to-real localization and robotic pickup.
