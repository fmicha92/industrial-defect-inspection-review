# PCB electronic component inspection dataset

## Definition

PCB component inspection data used by the conditional TransGAN paper. The paper reports 2544 images across optocoupler, diode, and capacitor classes, acquired with a BASLER camera setup and preprocessed to 418 x 418 images. The article data-availability statement points to the cTransGAN project repository.

## Why It Matters

This item supports industrial defect detection, anomaly detection, classification, segmentation, generation, or benchmark evaluation.

## Used In These Papers

- [[2023 - Conditional TransGAN-Based Data Augmentation for PCB Electronic Component Inspection]] uses this self-developed dataset for PCB component detection with cTransGAN-based augmentation.
