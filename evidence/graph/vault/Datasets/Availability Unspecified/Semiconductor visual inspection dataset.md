# Semiconductor visual inspection dataset

## Definition

Semiconductor visual fault inspection data used by the hybrid multistage DNN paper. The data consist of real-world wafer dicing microscope imagery from third-party manufacturers, with chips, streets, and street segments labeled for flawless, faulty, and anomalous inspection states. Public availability is not reported.

## Why It Matters

This item supports industrial defect detection, anomaly detection, classification, segmentation, generation, or benchmark evaluation.

## Used In These Papers

- [[2022 - Improving Automated Visual Fault Inspection for Semiconductor Manufacturing Using a Hybrid Multistage System of Deep Neural Networks]] evaluates SH-DNN on six wafer types with 33,136 streets and 1917 faulty streets.
- [[2025 - Simulation of semiconductor wafer dicing induced faults on chips]] uses five wafer types from earlier semiconductor visual inspection studies, reporting chip imagery resolutions from 224 x 224 to 912 x 908 pixels, 5,963 raw flawless chips, 1,026 raw faulty chips, and synthetic composite training sets for wafer dicing fault classification.
