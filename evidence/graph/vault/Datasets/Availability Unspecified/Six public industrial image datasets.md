# Six Public Industrial Image Datasets

## Definition

This note groups the six public industrial-related image datasets used by Apostolopoulos and Tzani: Casting, Defect, Magnetic Tile, Tech, Bridge, and Solar Cell defect. The processed text reports image counts and classes but does not fully define each source dataset.

## Why It Matters

The group is used to evaluate whether Multipath VGG19 generalizes across industrial object and defect recognition datasets.

## Used In These Papers


- [[2021 - Mixed Supervision for Surface-Defect Detection From Weakly to Fully Supervised Learning]] supports mixed supervision, surface defect detection.
- [[2023 - Industrial Object and Defect Recognition Utilizing Multilevel Feature Extraction]] evaluates MVGG19 on this six-dataset group.
