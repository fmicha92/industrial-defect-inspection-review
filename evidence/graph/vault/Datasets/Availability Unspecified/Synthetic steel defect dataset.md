# Synthetic steel defect dataset

## Definition

Synthetic steel defect dataset is the Blender-generated steel surface-defect dataset introduced by [[2021 - Synthetic Data Generation for Steel Defect Detection and Classification Using Deep Learning]]. It contains 6000 procedurally rendered images with automatically rendered masks.

## Why It Matters

It tests whether synthetic steel-surface data can train segmentation and classification models when real production defect images are scarce and expensive to annotate.

## Dataset Details

- Generation tool: Blender 3 with procedural shaders.
- Image count: 6000 synthetic defect images.
- Classes: four defect classes, 1500 images per class.
- Labels: black-and-white masks rendered alongside photorealistic defect images.
- Defect examples: cracks, bubbles, foreign inclusions, and surface irregularities.
- Availability: not reported; the source paper's data availability statement says not applicable.
