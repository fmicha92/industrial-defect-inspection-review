# Fabric Dataset

## Definition

Fabric Dataset is an availability-unspecified industrial fabric defect dataset used by [[2023 - EID-GAN Generative Adversarial Nets for Extremely Imbalanced Data Augmentation]] for extremely imbalanced data augmentation. The paper reports 100 negative samples with image size 3 x 1024 x 1024 and describes the outlier as occupying roughly 1/2000 of a negative image.

## Why It Matters

It supports evaluation or training for defect detection, localization, classification, segmentation, generation, or benchmark construction.

## Used In These Papers


- [[2023 - EID-GAN Generative Adversarial Nets for Extremely Imbalanced Data Augmentation]] uses Fabric as an extremely imbalanced dataset for EID-GAN tiny-outlier synthesis and Faster R-CNN generated-sample evaluation.
