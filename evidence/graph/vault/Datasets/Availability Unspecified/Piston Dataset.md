# Piston Dataset

## Definition

Piston Dataset is an availability-unspecified industrial piston defect dataset used by [[2023 - EID-GAN Generative Adversarial Nets for Extremely Imbalanced Data Augmentation]] for extremely imbalanced data augmentation. The paper reports 70 negative samples with image size 3 x 480 x 480 and describes the outlier as tiny relative to the full image.

## Why It Matters

It supports evaluation or training for defect detection, localization, classification, segmentation, generation, or benchmark construction.

## Used In These Papers


- [[2023 - EID-GAN Generative Adversarial Nets for Extremely Imbalanced Data Augmentation]] uses Piston to test whether EID-GAN can synthesize tiny outliers that other augmentation baselines fail to produce.
