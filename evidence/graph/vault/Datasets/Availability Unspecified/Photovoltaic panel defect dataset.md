# Photovoltaic Panel Defect Dataset

## Definition

Photovoltaic panel defect dataset represents photovoltaic inspection data when a source does not provide a stable public dataset name.

## Why It Matters

It anchors graph links for photovoltaic panel defect detection experiments without inventing a named dataset. When a source identifies PVEL-AD or its GitHub repository, use [[PVEL-AD]] instead.
