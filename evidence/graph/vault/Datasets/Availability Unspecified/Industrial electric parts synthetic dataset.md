# Industrial electric parts synthetic dataset

## Definition

The industrial electric parts synthetic dataset is a simulated dataset of 12 tiny electronic parts used for object detection training.

## Dataset Details

- Objects: 12 tiny electronic parts with accurate 3D CAD models.
- Synthetic training size: 10K samples in each reported experiment.
- Real data: 100 real test images; 256 real images used for Cyclic-GAN training.
- Availability: not reported.

## Related Papers

- [[2018 - Object Detection using Domain Randomization and Generative Adversarial Refinement of Synthetic Images]] uses this dataset to compare fixed-color synthetic data, randomized rendered data, GAN-refined data, and mixtures.
