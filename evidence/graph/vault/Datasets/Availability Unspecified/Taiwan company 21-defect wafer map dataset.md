# Taiwan Company 21-Defect Wafer Map Dataset

## Definition

This note refers to the 21-defect wafer-map dataset built with a Taiwan company in Tsai and Lee's wafer map classification paper. The processed text reports 16,388 wafer maps and 21 defect classes.

## Why It Matters

It is used to test whether lightweight wafer-map classification and autoencoder-decoder augmentation extend beyond the standard WM-811K classes.

## Used In These Papers

- [[2020 - A Light-Weight Neural Network for Wafer Map Classification Based on Data Augmentation]] reports 95.09% test accuracy after augmentation on the 21-defect dataset.
- [[2025 - Wafer Map Defect Classification Using Deep Learning Framework with Data Augmentation on Imbalance Datasets]] reports 16,388 wafer maps in 21 categories and improves F1-score from 80.58% without G2LGAN to 95.45% with G2LGAN.
