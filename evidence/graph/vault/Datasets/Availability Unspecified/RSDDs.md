# RSDDs

## Definition

RSDDs is recorded in the processed FMR-Net note as an evaluation dataset for visual inspection of textured surface defects. Availability: `not reported`.

## Why It Matters

It is one of the named datasets connecting FMR-Net to defect detection evaluation beyond MVTec AD.

## Used In These Papers

- [[2023 - A Feature Memory Rearrangement Network for Visual Inspection of Textured Surface Defects]] uses this dataset as reported in the processed paper note.
- [[2023 - Few-shot semantic segmentation for industrial defect recognition]] uses RSDDs as a source dataset for [[Industrial-5i]].
