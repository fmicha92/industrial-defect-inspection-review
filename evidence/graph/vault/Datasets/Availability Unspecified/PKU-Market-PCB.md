# PKU-Market-PCB

## Definition

PKU-Market-PCB is a printed circuit board surface defect dataset used for object detection in [[2024 - NHD-YOLO Improved YOLOv8 Using Optimized Neck and Head]]. The paper reports 693 original PCB images and six defect categories.

## Dataset Details

- Size: 693 original images.
- Classes: Spurious Copper, Short, Open Circuit, Missing Hole, Mouse Bite, and Spur.
- Split reported by NHD-YOLO: 493 training images and 200 testing images.
- Image handling: inputs resized to 640 x 640.
- Availability: not reported in the source text.
- License: not reported.

## Used In These Papers

- [[2024 - NHD-YOLO Improved YOLOv8 Using Optimized Neck and Head]] evaluates NHD-YOLOs on PKU-Market-PCB and reports AP improvement from 47.8% with YOLOv8s to 49.2%.
