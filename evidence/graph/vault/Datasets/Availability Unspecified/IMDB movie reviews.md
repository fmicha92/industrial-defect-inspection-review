# IMDB Movie Reviews

## Definition

IMDB movie reviews is a sentiment-review dataset used as sparse bag-of-words input in the Adam paper.

## Used In These Papers

- [[2015 - Adam A Method for Stochastic Optimization]] converts IMDB movie reviews to 10,000-dimensional bag-of-words vectors and applies 50% dropout noise for logistic regression optimizer comparison.
