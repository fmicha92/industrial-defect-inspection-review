# MPIIGaze

## Definition

MPIIGaze is a real eye-image dataset used to evaluate appearance-based gaze estimation.

## Dataset Details

- Reported size: 214K real images.
- Capture conditions: challenging illumination conditions.
- Availability: not reported.

## Related Papers

- [[2017 - Learning from Simulated and Unsupervised Images through Adversarial Training]] uses unlabeled MPIIGaze images for SimGAN refinement and evaluates gaze estimation on MPIIGaze.
