# Commutator Cylinder Surface Defect Dataset

## Definition

Commutator Cylinder Surface Defect Dataset contains industrial surface images of commutator cylinders, a core component of DC motors. The SDGAN paper uses an unlabeled binary version, CCSD-NL, and a labeled version, CCSD-L.

## Why It Matters

It supports defect image generation, binary anomaly recognition, and labeled defect classification under scarce defect data.

## Used In These Papers


- [[2020 - Defect Image Sample Generation With GAN for Improving Defect Recognition]] uses or reports [[Commutator Cylinder Surface Defect Dataset]] for defect image generation, GAN augmentation.

## Dataset Details

- CCSD-NL: defect-free images and defective images grouped into a binary recognition dataset without specific defect labels.
- CCSD-L: defect-free, thread-line, brushing, tin-residue, and wound classes.
- Source context: commutator cylinder surface defects appear during production.
