# WMT 2014 English-German

## Definition

WMT 2014 English-German is a machine-translation dataset used for English-to-German sequence transduction.

## Dataset Details

- Sentence pairs reported by the Transformer paper: about 4.5 million.
- Tokenization reported by the Transformer paper: byte-pair encoding with a shared source-target vocabulary of about 37,000 tokens.

## Used In These Papers

- [[2017 - Attention Is All You Need]] evaluates Transformer base and big models on WMT 2014 English-German.
