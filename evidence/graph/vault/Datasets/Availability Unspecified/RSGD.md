# RSGD

## Definition

RSGD is a recycled mobile screen glass defect dataset referenced by the GSDNet repository. The repository labels it as "Recycled Mobile Screen Defects" and lists a BaiduDisk link, but working download access is not confirmed.

## Why It Matters

RSGD supports [[Diverse glass surface defect detection]] for recycled screen-glass inspection, complementing [[SSGD]], which focuses on smartphone screen glass manufacturing defects.

## Used In These Papers

- [A lightweight and robust detection network for diverse glass surface defects via scale- and shape-aware feature extraction](https://doi.org/10.1016/j.engappai.2025.110640) provides the GSDNet code and dataset table that references RSGD.
