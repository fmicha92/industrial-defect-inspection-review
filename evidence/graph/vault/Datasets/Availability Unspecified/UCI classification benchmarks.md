# UCI Classification Benchmarks

## Definition

UCI classification benchmarks is a grouped note for the tabular classification datasets used in the Random Forests paper.

## Dataset Details

- The paper lists smaller and larger benchmark datasets including Glass, Breast cancer, Diabetes, Sonar, Vowel, Ionosphere, Vehicle, Soybean, German credit, Image, Ecoli, Votes, Liver, Letters, Sat-images, and Zip-code, plus synthetic datasets.

## Used In These Papers

- [[2001 - Random Forests]] evaluates Forest-RI, Forest-RC, Adaboost, and one-tree baselines across these classification datasets.
