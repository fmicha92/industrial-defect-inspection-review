# BeesBook marker dataset

## Definition

The BeesBook marker dataset contains honeybee marker images and labels used for marker decoding.

## Dataset Details

- Real data: 66K labeled tags from five time spans.
- Split: three time spans form a 40K training set; two time spans form a 26K test set.
- Generated data: RenderGAN generates 5 million marker images for decoder training.
- Availability: not reported.
