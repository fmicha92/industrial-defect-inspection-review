# CGD

## Definition

CGD is a construction glass defect dataset referenced by the GSDNet repository. The repository labels it as "Construction Glass Defects" and lists a BaiduDisk link, but working download access is not confirmed.

## Why It Matters

CGD supports [[Diverse glass surface defect detection]] for construction-glass inspection. It expands the glass inspection graph beyond mobile screens, aircraft canopies, laminated samples, optical glass, containers, bangles, and automotive glass.

## Used In These Papers

- [A lightweight and robust detection network for diverse glass surface defects via scale- and shape-aware feature extraction](https://doi.org/10.1016/j.engappai.2025.110640) provides the GSDNet code and dataset table that references CGD.
