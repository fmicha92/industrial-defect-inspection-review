# SQuAD v1.1

## Definition

SQuAD v1.1 is a question-answering dataset with questions and passages where the answer is a text span in the passage.

## Dataset Details

- The BERT paper reports 100,000 crowdsourced question-answer pairs.

## Used In These Papers

- [[2019 - BERT Pre-training of Deep Bidirectional Transformers for Language Understanding]] fine-tunes BERT for SQuAD v1.1 by predicting answer start and end positions.
