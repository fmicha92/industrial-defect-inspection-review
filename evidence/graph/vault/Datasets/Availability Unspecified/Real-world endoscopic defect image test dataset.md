# Real-world endoscopic defect image test dataset

## Definition

This dataset is recorded in the processed Schmedemann et al. note as 110 real-world test images for turbocharger housing inspection. Availability: `not reported`.

## Why It Matters

It is the held-out real-world evaluation counterpart for synthetic pretraining and real-data fine-tuning.
