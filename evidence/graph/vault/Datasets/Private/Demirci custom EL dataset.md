# Demirci custom EL dataset

## Definition

Demirci custom EL dataset is a confidential real-world photovoltaic electroluminescence image dataset used in [[2024 - Improved Hybrid Solar Cell Defect Detection Using GANs and Weighted Classification]] for binary solar-cell defect detection.

## Dataset Details

- Source: PV module EL data from a local manufacturer.
- Modality: electroluminescence images of monocrystalline and polycrystalline PV cells.
- Labels: functional and defective binary labels annotated by experts.
- Training images: 668.
- Test images: 468.
- Availability: confidential.
- License: not reported.

## Used In These Papers

- [[2024 - Improved Hybrid Solar Cell Defect Detection Using GANs and Weighted Classification]] uses the dataset for training and unseen test evaluation, reporting 93.08% accuracy, 94.36% recall, and 93.17% F-score.
