# Generated exports

Files in this directory are generated from `knowledge_graph/vault/` by `python -m inspection_evidence.cli export`.

They are committed to make the evidence snapshot usable without Obsidian or Python. Manual edits will be overwritten. Use `make export-check` to test synchronization.

Files whose names include `candidates` are automated pre-screens. They must not be presented as final review inclusion or eligibility decisions.
