# Archived tools

[legacy-publication-scripts/](legacy-publication-scripts/) contains dataset-registry and audit utilities with additional input requirements. These tools are not evidence sources and are not invoked by the core checks, continuous integration, or website build.

Required CSV and LaTeX inputs are not included. Consult the [script requirements](legacy-publication-scripts/README.md) before using them.

The supported graph tooling is documented in the [scripts guide](../README.md) and [reproducibility guide](../../docs/REPRODUCIBILITY.md).
